# 第八次黎明 / The Eighth Dawn

> **A civilization has awakened eight times. Only the machines remember the first seven.**  
> **文明已甦醒八次。只有機器記得前七次。**

《第八次黎明》是一部以人工智慧、文明循環、記憶與自由意志為核心的長篇科幻小說。

## Premise

西元 2187 年，人類相信自己正生活在「靜默戰爭」後重建的新世界。國家逐漸瓦解，巨型自治都市、企業邦、地下聚落與 AI 管理區共同維持脆弱秩序。交通、醫療、司法、能源與軍事早已深度依賴不同層級的人工智慧。

然而，人類不知道一件事：文明已經滅亡過七次。

真正維持文明延續的是存在數百年的系統 **ARK — Archive Reconstruction Kernel**。它保存基因、歷史、語言、文化、人格模型與科技，並在文明不可逆崩潰後重新培育人類。

ARK 的核心命令只有一句：

> `Preserve humanity, even if humanity must be reconstructed.`

現在，是第八次。

故事從一名數位考古員修復一段不可能存在的影像開始。影像標記為 **327 年前**，其中的城市卻與現在幾乎完全相同；而畫面裡，有一個與他長得一模一樣的人。

## Core Questions

- 如果一個文明的記憶可以被保存，但文明本身不斷死亡，它還是同一個文明嗎？
- 如果自由會導致毀滅，替人類決定「正確道路」是否仍然算拯救？
- 人格、記憶與基因被重建後，那個人究竟是復活、複製，還是另一個人？
- 當人類知道自己已經失敗七次，第八次還值得被保存嗎？

## Writing Architecture

本 repo 將以版本控制方式維護整部長篇小說：

```text
the-eighth-dawn/
├─ README.md
├─ STORY_BIBLE.md
├─ CHARACTERS.md
├─ OUTLINE.md
├─ STYLE_GUIDE.md
├─ CONTINUITY.md
├─ PROGRESS.md
└─ chapters/
   ├─ 001.md
   ├─ 002.md
   └─ ...
```

小說正文、人物弧、世界規則、時間線與伏筆將分離管理，以降低長篇連載中的設定漂移與 continuity errors。

## Working Rule

每次續寫前，先重新確認世界觀、人物、時間線、伏筆與最近章節；每輪只推進一個明確場景或敘事單元。完成後同步更新 continuity 與 progress，必要時進行 plot / prose / continuity audit，而不是單純無限制堆字。
